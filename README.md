# 📰 वार्ताप्राइम न्यूज़ (VartaPrime News)
### 30-मिनट ऑटोमेटेड RSS न्यूज़ फेचर, एडमिन अप्रूवल सिस्टम व लाइव पब्लिक न्यूज़ पोर्टल

वार्ताप्राइम न्यूज़ एक संपूर्ण हिंदी समाचार पोर्टल और ऑटोमेशन सिस्टम है। यह हर **30 मिनट** में मुफ़्त RSS फीड्स (Google News, अमर उजाला, दैनिक जागरण, नवभारत टाइम्स आदि) से ताज़ा खबरें स्वतः इकट्ठा करता है और उन्हें **एडमिन अप्रूवल पैनल (लंबित सूची)** में रखता है। जैसे ही आप किसी खबर को स्वीकृत (Approve) करते हैं, वह तुरंत मुख्य वेबसाइट पर लाइव हो जाती है।

---

## 🌟 प्रमुख विशेषताएं (Key Highlights)

- 🤖 **स्वचालित 30-मिनट क्रॉन जॉब**: हर 30 मिनट में 14 श्रेणियों (हरियाणा, देश, विदेश, राजनीति, बिज़नेस, क्राइम, शिक्षा, करियर, स्वास्थ्य, खेल, मनोरंजन, धर्म, लाइफस्टाइल) से ताज़ा खबरें लाना।
- 🛡️ **एडमिन अप्रूवल डैशबोर्ड (`/admin.html`)**:
  - **1-क्लिक अप्रूवल**: खबर को तुरंत वेबसाइट पर लाइव करें।
  - **एडिट व सुधार**: शीर्षक, फोटो या विवरण बदलकर लाइव करें।
  - **बल्क अप्रूवल (Bulk Approve)**: 10-20 खबरों को एक साथ 1 क्लिक में लाइव करें।
  - **खारिज (Reject)**: अनचाही खबरों को हटाएं।
  - **मैनुअल न्यूज़ राइटर**: खुद से एक्सक्लूसिव या स्थानीय खबरें लिखें।
  - **ऑटो-अप्रूवल टॉगल**: चाहें तो अप्रूवल बंद करके खबरों को सीधे लाइव करने का विकल्प।
  - **RSS स्रोत प्रबंधन**: नए RSS लिंक जोड़ना या हटाना।
- 📰 **प्रीमियम पब्लिक न्यूज़ पोर्टल (`/`)**:
  - भारतीय समाचार पत्र स्टाइल (देवनागरी फॉन्ट्स: Noto Serif Devanagari, Hind, Teko)।
  - लाइव ब्रेकिंग न्यूज़ टिकर, टॉप लीड स्टोरीज, ट्रेंडिंग साइडबार।
  - फुल आर्टिकल रीडर मोडल, WhatsApp/Facebook शेयरिंग।
  - लाइव सर्च और श्रेणी टैब्स।
  - लाइव ऑटो-रिफ्रेश (बिना पेज रीलोड किए नई अप्रूव्ड खबरें दिखती हैं)।

## 🚀 कैसे शुरू करें (How to Run Locally)

### विकल्प 1: 1-क्लिक में शुरू करें (Windows Batch)
प्रोजेक्ट फोल्डर में मौजूद `start.bat` फाइल पर डबल क्लिक करें।

### विकल्प 2: टर्मिनल/कमांड प्रॉम्प्ट से
```bash
cd C:\Users\Administrator\.gemini\antigravity\scratch\vartaprime-news
node server.js
```

ब्राउज़र में खोलें:
- 🌐 **पब्लिक न्यूज़ वेबसाइट**: [http://localhost:3000](http://localhost:3000)
- 🛡️ **एडमिन अप्रूवल डैशबोर्ड**: [http://localhost:3000/admin.html](http://localhost:3000/admin.html)

## 🌐 ऑनलाइन होस्ट कैसे करें (Deployment Guide)

### 1. Render.com / Railway.app / VPS (Recommended)
1. इस कोड को अपने GitHub रिपॉजिटरी में पुश करें।
2. Render.com या Railway पर "New Web Service" चुनें।
3. Build Command: `npm install`
4. Start Command: `node server.js`
5. आपकी लाइव वेबसाइट और एडमिन पैनल 24x7 ऑनलाइन चलेगा और हर 30 मिनट में खुद बैकग्राउंड में खबरें लाएगा।

### 2. वैकल्पिक Google Sheets विधि (Zero Cost)
यदि आप बिना Node.js सर्वर के चलाना चाहते हैं:
1. Google Sheets खोलें और Extensions > Apps Script में जाएं।
2. `google-apps-script/Code.gs` का कोड पेस्ट करें और `setupSheets` फंक्शन चलाएं।
3. Deploy > New Deployment > Web App (Access: Anyone) करें।
4. प्राप्त URL को अपनी वेबसाइट में API URL के रूप में इस्तेमाल करें।
